# Dívida técnica

| Item                                                            | Impacto                                                                                                                                                                                                       | Gatilho para resolver                                                                                               |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Swagger omite schemas de bilhete/pessoa/venda                   | bloqueia DTOs live                                                                                                                                                                                            | backend publicar schemas ou exemplos                                                                                |
| `estabelecimento_id` não fornecido                              | bloqueia listagem real                                                                                                                                                                                        | configurar ID correto da loja                                                                                       |
| Formato de item de bilhete live não observado                   | bloqueia validação live                                                                                                                                                                                       | obter concurso ativo com bilhetes                                                                                   |
| Endpoint de reserva em `bilhete.reservado` não publicado        | reserva externa desligada                                                                                                                                                                                     | API publicar `PUT`/`GET` condicionais; ajustar `RESERVATION_PATH` e ativar `live`                                   |
| Token de reserva é `data_reservado` (precisão de segundos)      | reenvio raro libera trava alheia                                                                                                                                                                              | API aceitar token próprio (coluna nova ou `numorder`)                                                               |
| `PUT /bilhete/validar` não é condicional à reserva              | janela entre conferência e validação                                                                                                                                                                          | API validar só com `validado = 0` e token da reserva                                                                |
| Surpresinha não troca bilhete em conflito externo               | cliente precisa tentar de novo                                                                                                                                                                                | medir frequência de `TICKET_RESERVED` em surpresinha                                                                |
| Fontes dependem do Google Fonts                                 | aparência offline                                                                                                                                                                                             | hospedar fontes antes de produção                                                                                   |
| Política legal do sorteio não fornecida                         | lançamento                                                                                                                                                                                                    | definir regulamento, elegibilidade e privacidade                                                                    |
| Disponíveis vêm com `lote_validacao` vazio e `posicao_lote` 0   | compra live não valida bilhete                                                                                                                                                                                | confirmar com a API de bilhetes quais valores enviar em `PUT /bilhete/validar`                                      |
| API de bilhetes só responde por HTTP                            | CPF/telefone sem TLS                                                                                                                                                                                          | origem HTTPS oficial; remover `TICKET_API_ALLOW_HTTP`                                                               |
| Limites por IP em memória dependem de `TRUST_PROXY`             | sem a variável atrás de proxy, todos dividem o limite                                                                                                                                                         | definir `TRUST_PROXY` no deploy; usar armazenamento compartilhado com várias instâncias                             |
| Escrita de `/concurso` sem autenticação na API de bilhetes      | qualquer um altera ou apaga concursos                                                                                                                                                                         | API exigir credencial nas rotas de escrita                                                                          |
| `identify` revela se o CPF tem cadastro                         | enumeração de CPFs cadastrados (limitada por IP)                                                                                                                                                              | abuso observado ou exigência LGPD                                                                                   |
| Senha do cliente vai à API de bilhetes por HTTP                 | senha sem TLS entre backend e API                                                                                                                                                                             | origem HTTPS oficial                                                                                                |
| Limites de login e código em memória                            | reinício zera contadores; várias instâncias não compartilham                                                                                                                                                  | mais de uma instância ou abuso                                                                                      |
| Bloqueio por CPF no login e no código permite travar uma vítima | quem sabe o CPF impede o acesso por 15 minutos (login) ou 1 hora (código)                                                                                                                                     | abuso observado; considerar bloqueio por par IP+CPF ou desafio                                                      |
| `POST /pessoa/cadastro` não validado contra a API real          | campos de endereço, edição sem reenviar senha e resposta sem `pessoas_id` não confirmados; falha só aparece em produção                                                                                       | executar a Tarefa 0 do plano com CPF de teste autorizado                                                            |
| CPF "sequestrado" no cadastro                                   | quem cadastra antes um CPF que ainda não está na API usa o próprio e-mail; o titular não recupera sozinho ("Esqueci a senha" vai ao e-mail de quem cadastrou e o código do admin é recusado porque há e-mail) | hoje, runbook manual em `docs/SECURITY.md`; criar ação no painel para redefinir o e-mail após conferir a identidade |
| E-mail legado da API não verificado                             | e-mail digitado no checkout anônimo antigo foi gravado na API sem confirmação e recebe o código de primeiro acesso; e-mail errado ou de terceiro entrega o acesso a outra pessoa                              | reclamação de acesso indevido; considerar confirmar o titular antes do primeiro acesso de CPFs antigos              |
| Sem limite de envio por destinatário nem teto diário            | pedidos de código repetidos (CPFs ou IPs diferentes) esgotam a cota do SMTP gratuito e ninguém mais recebe código                                                                                             | antes de abrir ao público ou ao primeiro `MAIL_UNAVAILABLE` por cota; limitar por e-mail e por dia                  |
| "Esqueci a senha" pode ser bloqueado por reenvio                | quem sabe o CPF pede código novo a cada 60 s e invalida o anterior, impedindo o titular de concluir (soma-se ao bloqueio por CPF já aceito)                                                                   | abuso observado; não invalidar o código anterior ou exigir desafio no reenvio                                       |
| Cookie de sessão sem `maxAge`                                   | a sessão do cliente acaba ao fechar o navegador, diferente do combinado "30 dias sem uso" (que vale só no servidor)                                                                                           | pedido do cliente; definir `maxAge` alinhado a `SESSION_IDLE_MS`                                                    |
| `verification_codes` nunca é limpo                              | tabela cresce sem limite e guarda hashes e e-mails antigos além do necessário                                                                                                                                 | volume no banco ou política de retenção LGPD; apagar códigos usados ou expirados periodicamente                     |
